# Encrypted automation backups

`node scripts/backup-n8n.mjs` makes online consistent SQLite snapshots of n8n, coordinator run history and private source intake using node:sqlite backup(), through temporary read-only mounts of only the two dedicated project volumes. It copies required private service/auth material into a0700temporary directory, creates a tar archive, encrypts it using AES-256-GCM with a random32byte key and fresh nonce, and deletes plaintext staging after completion. It never stops unrelated services or restores over production files.

Each run decrypts into a separate temporary directory, validates SQLite integrity, checks workflow/run/lead row counts and compares required private credential fingerprints, then deletes that restore directory. Wrong keys/tampering fail authentication and remove incomplete plaintext. Existing restore targets are never overwritten. Unit tests cover these guarantees.

Local encrypted snapshots: `.private/n8n/backups/*.toa-backup`; latest nonsensitive status: `latest.json`. Retention:7local encrypted snapshots. Key file: `.private/n8n/secrets/backup_key`,0600; never print it. A separate encrypted Cloudflare Worker secret `BACKUP_ENCRYPTION_KEY` stores its base64 encoding for disaster recovery. No public API returns this key, and it is not mounted into the Codex container. In disaster recovery, an account owner must use private authorized Cloudflare administration to recover that binding into a0600file; never paste it into chat/issues or add a public recovery endpoint. Losing both the local key and Cloudflare account access makes the encrypted archive unrecoverable.

For manual recovery, keep production services paused, decrypt with scripts/lib/news-backup.mjs into a new private directory, inspect archive paths and manifest, validate databases/credential matches, then restore deliberately to new isolated volumes before any production replacement. n8n's matching encryption key is mandatory. Do not run `down -v` against live volumes. Use the source repository to rebuild service images and reauthenticate privately if the Codex account grant expired.
