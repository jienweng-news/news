# Server-rendered editorial assets

`editorial-logo.svg` is the approved first-party Token on Air wordmark, copied from public/brand for safe raw bundling into social graphics. Keep both copies aligned when changing the brand.

`barlow-condensed-bold.ttf` is the same Barlow font served in public/fonts. Licence: public/fonts/OFL.txt. The inline import lets the server render vector outlines without host-installed fonts or runtime file/network access. Graphics use the original English headline across editions; article metadata, alt text and page copy remain localized.
